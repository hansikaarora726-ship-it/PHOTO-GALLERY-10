Photo Gallery

📌 Project Overview

The Photo Gallery is a responsive webpage created using HTML and CSS. It displays beautiful photographs in a clean grid layout with titles and hover effects.

🎯 Objectives

* Create an attractive photo gallery.
* Use CSS Grid to arrange images.
* Make the gallery responsive for different screen sizes.
* Add hover effects to photo cards.
* Practice HTML and CSS concepts.

🛠️ Technologies Used

* HTML5
* CSS3

✨ Features

* Responsive photo grid layout.
* Six photo cards with captions.
* Hover animation on photo cards.
* Rounded corners and box shadows.
* Media queries for tablet and mobile screens.
* Simple and attractive design.

📂 Project Structure

Photo-Gallery/
│
├── index.html

🚀 How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in your browser.
4. Alternatively, use the Live Server extension.

Note: An internet connection is required to load the online images.

📚 Learning Outcomes

* Understanding HTML page structure.
* Using CSS Grid for layouts.
* Applying hover effects and box shadows.
* Using media queries for responsive design.
* Improving webpage styling skills.
